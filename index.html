Claude Agent Skills are folders with a SKILL.md file of instructions (and sometimes scripts) that teach Claude how to do a specific task well, like building slide decks, filling PDF forms or writing tests.

Click “View SKILL.md” to read the skill and install it in Claude.ai, Claude Code (~/.claude/skills/) or the API, or click “Copy prompt with skill” to copy your prompt rewritten to use that skill.
