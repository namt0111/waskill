What is this? · FAQ

Waskill helps you pick a Claude skill for the task you're about to ask Claude to do. Type your prompt, and it shows the 5 best-matching skills from popular open-source GitHub repos.

What are Claude skills?

Claude Agent Skills are folders with a SKILL.md file of instructions (and sometimes scripts) that teach Claude how to do a specific task well, like building slide decks, filling PDF forms or writing tests.

How do I use a skill Waskill suggests?

Click “View SKILL.md” to read the skill and install it in Claude.ai, Claude Code (~/.claude/skills/) or the API, or click “Copy prompt with skill” to copy your prompt rewritten to use that skill.

Where do the skills come from?

Waskill indexes SKILL.md files from popular public GitHub repositories with 100+ stars. Waskill is free and not affiliated with Anthropic.

Is my prompt sent anywhere?

No. Matching runs entirely in your browser.
